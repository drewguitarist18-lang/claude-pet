What he does

See what Claude is doing at a glance.

Clawd reads Claude Code's hook events: each tool it runs, each time it stops, each time it needs an answer. You don't need to keep the terminal on screen.

Working

Types on his laptop. The bubble shows the current action, like "Editing app.py".

Always one click away

Click Clawd, land in Claude.

He stays on your desktop like a little dock icon with feelings. Click him and you're back in Claude, right at the session that needs you.

  • Starts with WindowsHe's there when you sign in and naps while nothing is running.
  • Jumps to ClaudeA click brings up the session waiting on you, or opens the Claude app if it's closed.
  • Ignores background agentsScripts running claude -p or the Agent SDK don't wake him.
  • Or only with ClaudeTurn off "Always on screen" and he shows up with Claude and leaves when you're done.

Install

About a minute, start to finish.

Download the installer

ClaudePetSetup.exe. You don't need Python or any admin rights.

Run it

It installs Clawd for your user and adds his hooks to Claude Code. If Windows SmartScreen warns you, click More info, then Run anyway.

Open Claude

Start the Claude app or claude in a terminal and send a message. Clawd walks onto your screen.

Already have Python? Install it as a Claude Code plugin

Run these inside Claude Code. The plugin runs from source, so you'll need Python 3 on your PATH.

/plugin marketplace add drewguitarist18-lang/claude-pet
/plugin install claude-pet@claude-pet
Questions

Good to know.

Does it send anything anywhere?

No. Clawd reads the hook events Claude Code passes him on your computer and keeps a few small files in ~/.claude-pet. He makes no network requests.

Does it slow Claude down?

Barely. Each hook takes a fraction of a second, and Clawd runs as his own small process.

Mac or Linux?

Windows only for now. The pet uses Windows APIs to tell when the Claude window is open.

How do I remove it?

Uninstall it from Windows Settings → Apps. That also takes his hooks back out of Claude Code's settings.

Can I change his context window size?

He assumes 200k tokens and switches to 1M on his own when a session goes past that. To set a size yourself, add "context_window" to ~/.claude-pet/config.json.

Is this made by Anthropic?

No. It's an independent, open-source fan project built for Claude Code users.
